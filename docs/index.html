언제 집에 갈 수 있는지 알려줍니다.

macOS용 내려받기 Windows용 내려받기

v1.1 · macOS 470KB · Windows 68MB · 모든 버전

기능

자동 출근 기록

잠금을 풀거나 절전에서 깨어나면 그 시각을 출근으로 기록합니다. 오전 8시~오후 3시 사이 첫 신호에만 적용되고, 그날 기록이 이미 있으면 건너뜁니다. 시각이 틀리면 직접 고칠 수 있습니다.

퇴근 예정 시각

출근 + 9시간. 반차는 4시간 근무에 12~13시 점심을 제외하고 계산합니다.

반차

체크박스로 켜고 끕니다. 출근이 오후 1시~3시 사이에 기록되면 자동으로 켜집니다.

퇴근 알림

10분 전과 정각에 알림이 옵니다. 아이콘은 퇴근 30분 전부터 주황에서 빨강으로 바뀝니다.

근무 기록

최근 10일치. 날짜별 출퇴근 시각과 근무 시간을 보여주고, 9시간을 넘긴 날은 빨갛게 표시합니다.

자동 실행

로그인할 때 자동으로 시작합니다. 잠금 해제를 감지하려면 켜두어야 합니다.

설치 — macOS

  1. 위 macOS용 내려받기 를 누릅니다.
  2. 받은 gohome.zip 의 압축을 풉니다.
  3. 풀린 폴더 안의 install.command 를 더블클릭합니다.
  4. 메뉴 막대에 집 모양 아이콘이 생기면 끝입니다.

이렇게 안 되면

“확인되지 않은 개발자” 경고가 떠서 안 열린다면
시스템 설정 → 개인정보 보호 및 보안 을 열고, 아래쪽 무시하고 열기 를 누른 뒤 다시 더블클릭합니다. 서명이 없는 앱이라 처음 한 번만 필요합니다.
“gohome.app 을 찾을 수 없습니다” 가 뜬다면
압축을 풀지 않고 실행한 경우입니다. zip 을 먼저 풀고, 풀린 폴더 안의 install.command 를 실행합니다.

설치 — Windows

  1. 위 Windows용 내려받기 를 누릅니다.
  2. 받은 GoHome.exe 를 계속 둘 폴더로 옮깁니다. 나중에 옮기면 자동 실행이 풀립니다.
  3. 더블클릭해서 실행합니다. 설치 과정은 없습니다.
  4. 작업 표시줄 오른쪽에 집 모양 아이콘이 생기면 끝입니다.

이렇게 안 되면

“Windows에서 PC를 보호했습니다” 창이 뜬다면
추가 정보 를 누르고 실행 을 고릅니다. 서명이 없어서 처음 한 번만 뜹니다.
실행했는데 아이콘이 안 보인다면
숨겨진 아이콘 안에 들어간 경우입니다. 작업 표시줄의 ^ 를 눌러 확인하고, 아이콘을 밖으로 끌어내면 계속 보입니다.
자동 실행을 켰는데 재부팅 후 안 뜬다면
exe 를 다른 폴더로 옮긴 경우입니다. 트레이 아이콘 우클릭 메뉴에서 자동 실행을 껐다가 다시 켜면 지금 위치로 다시 잡힙니다.
