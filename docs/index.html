언제 집에 갈 수 있는지 알려줍니다.

macOS용 내려받기 Windows용 내려받기

v1.0 · macOS 470KB · Windows 68MB · 모든 버전

하는 일

출근을 자동으로 찍습니다

아침에 맥 잠금을 풀거나 절전에서 깨우면 그 시각이 출근으로 기록됩니다. 오전 8시부터 오후 3시 사이 첫 신호에만, 그날 기록이 없을 때만 찍힙니다. 시각이 엉뚱하면 팝오버에서 눌러 고칠 수 있습니다.

퇴근 예정 시각을 계산합니다

기본은 출근 + 9시간입니다. 반차를 켜면 4시간 근무로 잡고 12~13시 점심을 빼고 계산합니다.

반차는 체크박스로 켭니다

팝오버의 “오늘 반차” 하나면 됩니다. 출근이 오후 1시에서 3시 사이에 찍히면 오후 반차로 보고 알아서 켜집니다.

아이콘이 색으로 알려줍니다

퇴근 30분 전부터 아이콘이 주황에서 빨강으로 물듭니다. 10분 전과 정각에는 알림이 뜹니다.

최근 10일치가 남습니다

날짜별 출퇴근 시각과 근무 시간을 볼 수 있고, 9시간을 넘긴 날은 빨갛게 표시됩니다.

설치 — macOS

  1. 버튼으로 gohome.zip 을 받고 압축을 풉니다.
  2. 나온 폴더에서 install.command 를 더블클릭합니다.
  3. 메뉴바에 집 모양 아이콘이 생기면 끝입니다.

왜 스크립트를 실행해야 하나요?
애플 개발자 인증서 없이 만든 앱이라 그냥 열면 macOS가 막습니다. install.command 는 앱을 /Applications 로 옮기고 그 격리 표시를 떼는 일만 합니다. 무슨 일을 하는지는 빌드 스크립트에서 그대로 볼 수 있습니다.

설치 — Windows

  1. 버튼으로 GoHome.exe 를 받습니다. 설치 과정이 따로 없습니다.
  2. 계속 둘 폴더로 먼저 옮깁니다. 자동 실행을 켜면 그 시점의 경로를 기억하기 때문에, 나중에 파일을 옮기면 자동 실행이 깨집니다.
  3. 실행하면 트레이에 집 모양 아이콘이 생깁니다.

“Windows에서 PC를 보호했습니다” 창이 뜹니다.
코드 서명 인증서가 없어서 처음 실행할 때 한 번 뜹니다. 추가 정보 를 누르고 실행 을 고르면 됩니다. 다음부터는 안 뜹니다.

.NET 설치는 필요 없습니다.
런타임을 앱 안에 넣어 만들어서 exe 하나로 돌아갑니다. 68MB인 이유가 이겁니다.

알아둘 것

필요 버전macOS 14 이상 / Windows 10 이상 (64비트)
기록 저장 위치맥은 ~/Library/Application Support/gohome/, 윈도우는 %APPDATA%\gohome\ 안의 JSON 파일 하나. 어디로도 전송되지 않습니다.
상주잠금 해제를 감지해야 하므로 설정에서 자동 실행을 켜두는 편이 낫습니다.
기준 시각한국 시간(KST) 고정
